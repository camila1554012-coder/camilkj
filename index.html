Preguntas Frecuentes

¿La prueba tiene algún costo?

No. La prueba inicial propuesta dentro del proyecto de aula es 100% gratuita para el tendero.

¿Necesito conocimientos de sistemas?

Para nada. El sistema está diseñado pensando en el consumidor práctico: no requiere instalar programas ni tener experiencia en código.

¿Cómo se reciben los pagos?

El pago se acuerda de forma directa entre el tendero y el cliente final (efectivo contra entrega, Nequi o Daviplata).
